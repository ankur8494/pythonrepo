# Green Digital Clock

`code.py` is a small desktop clock built with Python's Tkinter GUI library. It
shows the current time and date in a simple window with a green background and
white text.

## Features

- Displays the current time in 12-hour format, including seconds and AM/PM.
- Shows the current weekday, month, day, and year.
- Refreshes the display every second.
- Uses a fixed-size window with a green background.

## Requirements

- Python 3
- Tkinter (typically included with standard Python installations)

## Run

Open a terminal in this folder and run:

```powershell
python code.py
```

On Windows, if `python` is not recognized, try:

```powershell
py code.py
```

Close the clock window to exit the program.
